# 🛍️ StyleHub-Online-Store

This project was created as part of the final project for the **"Women in AI"** course at **Business and Technology University**, focusing on front-end development.

It is a responsive **e-commerce website** built using modern web technologies and showcases a user-friendly shopping experience with various features for browsing, selecting, searching, and managing products.

---

## 🌐 Live Demo

🔗 [Live Website](https://style-hub-online-store.vercel.app/)  
📁 [GitHub Repository](https://github.com/Miranda-K12/StyleHub-Online-Store)

---

## 🚀 Features

- 🧾 **Product Catalog** – Browse and view product details.
- 🔍 **Search Functionality** – Easily search for products by name.
- 🛒 **Shopping Basket** – Add items to the cart and choose size before checkout.
- ❤️ **Wishlist** – Save favorite products for later.
- 💾 **Local Storage** – Persist cart and wishlist data across sessions.
- 🔀 **Routing** – Seamless navigation with React Router.
- 📱 **Responsive Design** – Works on all screen sizes.
- 🔄 **Data Fetching** – Products are fetched from a local server.
- 🧩 **Reusable Components** – Clean and modular component structure for scalability.

---

## 🛠️ Tech Stack

- **React + Vite** – Fast and modern web development environment.
- **React Router** – For page navigation and route management.
- **Material UI (MUI)** – For stylish and consistent UI components.
- **Redux Toolkit** – Global state management (basket, wishlist, products).
- **Swiper.js** – Interactive product sliders and carousels.
- **LocalStorage** – To store cart and wishlist data locally.
- **Custom Components** – Modular and reusable UI components.
